# Python Mini Projects 🐍

Коллекция небольших проектов на Python для практики и портфолио. Репозиторий будет постепенно пополняться новыми играми и приложениями.

## Проекты

| Проект | Описание | Технологии |
|---|---|---|
| [Pixel Snake Deluxe](snake_game/) | Пиксельная змейка с режимами, препятствиями, бонусами, рекордами и цветовыми темами | Python, Pygame CE |

## Запуск проектов

Каждый проект находится в отдельной папке и содержит собственную инструкцию по установке и запуску.

Для запуска Pixel Snake Deluxe:

```powershell
cd snake_game
py -m pip install -r requirements.txt
py main.py
```
