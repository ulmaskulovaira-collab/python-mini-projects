# Pixel Snake Deluxe 🐍

Пиксельная «Змейка» на Python и Pygame Community Edition — небольшая аркада с режимами, бонусами, препятствиями и таблицей рекордов.

## Возможности

- стартовое меню и три уровня сложности;
- режимы «Классика», «Сквозь стены», «На время» и «Два игрока»;
- препятствия на обычной и сложной трудности;
- обычное яблоко, золотое яблоко `+3` и замедляющая ягода;
- пиксельные частицы, звуки и фоновая мелодия без дополнительных файлов;
- пять лучших результатов с именем, режимом и датой;
- темы Clover, Cyber и Game Boy;
- сохранение темы, звука и рекордов между запусками.

## Установка и запуск

Требуется Python 3.10 или новее.

```powershell
py -m pip install -r requirements.txt
py main.py
```

Используется `pygame-ce`, включая поддержку Python 3.14. В коде библиотека импортируется командой `import pygame`.

## Управление

### Меню

| Клавиши | Действие |
|---|---|
| `↑` `↓` или `W` `S` | Выбор пункта |
| `←` `→` или `A` `D` | Изменение значения |
| `Enter` или `Пробел` | Подтверждение |
| `Esc` | Назад или выход |

### Игра

| Клавиши | Действие |
|---|---|
| Стрелки | Первый игрок |
| `WASD` | Второй игрок либо первый в одиночном режиме |
| `Пробел` | Пауза |
| `Esc` | Главное меню |

После проигрыша введите имя и нажмите `Enter`, чтобы сохранить результат и начать заново.

## Виды еды

| Еда | Эффект |
|---|---|
| Розовое яблоко | `+1` очко |
| Золотое яблоко | `+3` очка, исчезает через 6 секунд |
| Синяя ягода | `+1` очко и замедление на 5 секунд |
