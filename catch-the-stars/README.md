# Лови звёзды ⭐

Небольшая аркадная игра на Python и Pygame. Передвигай корзинку, лови падающие звёзды и постарайся установить новый рекорд.

## Возможности

- управление стрелками или клавишами `A` и `D`;
- три жизни;
- постепенное увеличение сложности;
- сохранение рекорда между запусками;
- перезапуск без закрытия игры;
- игровые изображения находятся в папке `assets`: фон, корзина, звезда и сердечко жизни.
- элементы масштабируются внутри игры в единых пропорциях: корзина 160×72, звезда 44×44, сердечки 26×26.
- звезда засчитывается только при попадании внутрь верхней части корзины.
- стартовое меню, пауза и обновлённый экран окончания игры выполнены в едином монохромном стиле;
- клавиша `P` ставит игру на паузу, `M` включает и выключает звук;
- короткие ретро-звуки генерируются самой игрой и не требуют дополнительных файлов;
- при поимке появляются пиксельные частицы, а при промахе — короткая красная вспышка;
- редкая бонусная звезда отличается оттенком и приносит 3 очка;
- скорость и частота появления звёзд постепенно растут вместе с уровнем.

## Как запустить

### Самый простой способ для Windows

Распакуй ZIP-архив и дважды нажми на файл `START_GAME.bat`. Он сам установит Pygame при первом запуске и откроет игру.

### Запуск через терминал

Установи Python 3.10 или новее, затем выполни в папке проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

Если команда `python` не работает в Windows, попробуй:

```bash
py -m pip install -r requirements.txt
py main.py
```

## Управление

| Клавиши | Действие |
|---|---|
| `←` / `A` | Двигаться влево |
| `→` / `D` | Двигаться вправо |
| `P` | Пауза / продолжить |
| `M` | Включить или выключить звук |
| `R` | Начать заново после проигрыша |
| `Esc` | Пауза; в меню или после проигрыша — выход |

## Правила

За каждую пойманную звезду начисляется одно очко. Если звезда упала мимо корзинки, теряется одна жизнь. После трёх пропущенных звёзд игра заканчивается.
