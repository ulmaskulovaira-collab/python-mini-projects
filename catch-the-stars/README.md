# Лови звёзды ⭐

Небольшая аркадная игра на Python и Pygame. Передвигай корзинку, лови падающие звёзды и постарайся установить новый рекорд.

## Возможности

- управление стрелками или клавишами `A` и `D`;
- три режима сложности с разной скоростью, частотой падения и количеством жизней;
- постепенное увеличение сложности;
- сохранение рекорда между запусками;
- перезапуск без закрытия игры;
- игровые изображения находятся в папке `assets`: фон, корзина, звезда и сердечко жизни.
- элементы масштабируются внутри игры в единых пропорциях: корзина 160×72, звезда 44×44, сердечки 26×26.
- звезда засчитывается только при попадании внутрь верхней части корзины.
- стартовое меню, пауза и обновлённый экран окончания игры выполнены в едином монохромном стиле;
- клавиша `P` ставит игру на паузу, `M` включает и выключает звук;
- короткие ретро-звуки генерируются самой игрой и не требуют дополнительных файлов;
- при поимке появляются пиксельные частицы, а при промахе — короткая красная вспышка;
- редкая бонусная звезда отличается оттенком и приносит 3 очка;
- скорость и частота появления звёзд постепенно растут вместе с уровнем.
- текст отрисовывается в чётком пиксельном стиле без сглаживания;
- после трёх удачных поимок включается комбо-множитель `×2`;
- розовая звезда восстанавливает жизнь, максимум можно накопить пять жизней;
- тёмную звезду с крестом нужно пропускать: при поимке она отнимает жизнь;
- перед началом раунда появляется обратный отсчёт `3… 2… 1…`;
- корзина реагирует на поимку, а звёзды слегка мерцают;
- фон дополнен медленно движущимися пиксельными огнями;
- окно можно свободно изменять без искажения пропорций игры.
- перед появлением каждой звезды сверху показывается предупреждающий указатель;
- шкала комбо постепенно опустошается: следующую звезду нужно поймать вовремя;
- над корзиной появляются подписи `+1`, `+3`, `+ЖИЗНЬ` или `-1 ЖИЗНЬ`;
- после проигрыша показываются время игры, промахи, специальные звёзды и лучшее комбо;
- специальные звёзды используют отдельные нарисованные пиксельные спрайты.

## Как запустить

### Самый простой способ для Windows

Распакуй ZIP-архив и дважды нажми на файл `START_GAME.bat`. Он сам установит Pygame при первом запуске и откроет игру.

### Запуск через терминал

Установи Python 3.10 или новее, затем выполни в папке проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

Если команда `python` не работает в Windows, попробуй:

```bash
py -m pip install -r requirements.txt
py main.py
```

### Создание EXE

Дважды нажми `BUILD_EXE.bat`. Скрипт установит PyInstaller и создаст готовый файл:

```text
dist/CatchTheStars.exe
```

Для репозитория можно подключить GitHub Actions: workflow собирает Windows-версию и сохраняет её как артефакт `CatchTheStars-Windows`.

## Управление

| Клавиши | Действие |
|---|---|
| `←` / `A` | Двигаться влево |
| `→` / `D` | Двигаться вправо |
| `P` | Пауза / продолжить |
| `M` | Включить или выключить звук |
| `F11` | Полноэкранный или оконный режим |
| `1` / `2` / `3` | Выбор сложности в главном меню |
| `R` | Начать заново после проигрыша |
| `Esc` | Пауза; в меню или после проигрыша — выход |

## Правила

Обычная звезда приносит одно очко, синяя бонусная — три очка, розовая восстанавливает жизнь. После трёх удачных поимок очки умножаются на два. Любой промах сбрасывает комбо и отнимает жизнь. Тёмную звезду с крестом, наоборот, нужно пропустить: если поймать её, потеряется жизнь. Игра заканчивается, когда не остаётся жизней.
